# Введение

В последние годы методы искусственного интеллекта находят широкое применение в задачах принятия решений в условиях неопределённости. Одним из наиболее результативных среди них является поиск по дереву методом Монте-Карло (Monte Carlo Tree Search) — эвристический алгоритм, который позволяет программным агентам принимать решения на уровне, сопоставимом с человеческим. Поиск по дереву методом Монте-Карло широко используется в задачах планирования, частным случаем которых является игра: в этом случае задача планирования сводится к поиску оптимальной стратегии. В современных программных агентах применяются различные вариации этого метода, отличающиеся стратегиями выбора, расширения и распространения оценок.

Понимание поведения конкретной вариации метода для конкретной игры, а также отладка новой вариации существенно затруднены. Это связано с динамическим, несимметричным построением дерева поиска, случайной природой симуляций и постоянным обновлением статистики в узлах. Дополнительную сложность создаёт размер дерева: даже при умеренном числе итераций оно содержит тысячи узлов, а за полную партию — десятки тысяч, что значительно превышает число элементов, одновременно различимых на экране.

В рамках предшествующей выпускной квалификационной работы бакалавра в программной среде общего игрового искусственного интеллекта GGP Base Package был разработан модуль, визуализирующий построение дерева поиска методом Монте-Карло и обеспечивающий наблюдение за его ростом. Этот модуль решил задачу динамической визуализации на сравнительно небольших деревьях, однако при увеличении числа узлов его представление в виде узлов-кругов теряет читаемость, а управление детализацией требует ручной настройки фильтров и возлагается на исследователя. Таким образом, актуальной является задача наглядного и масштабируемого представления больших деревьев поиска, при котором уровень детализации автоматически согласуется с масштабом отображения. Решение этой задачи предоставляют методы семантического масштабирования, при которых изменение масштаба меняет не только размер, но и состав отображаемой информации: при отдалении видны лишь доминирующие ветви дерева, при приближении — детали выбранного поддерева.

Применение методов семантического масштабирования к визуализации поиска по дереву методом Монте-Карло требует учёта особенностей такого дерева — неоднородности распределения посещений, переиспользования дерева между ходами игры и независимости от конкретной игры, обусловленной использованием платформы общего игрового искусственного интеллекта.

**Целью** работы является повышение наглядности и масштабируемости визуализации построения дерева поиска методом Монте-Карло в программной среде GGP Base Package за счёт применения методов семантического масштабирования.

Для достижения поставленной цели необходимо решить следующие **задачи**:
1. проанализировать особенности дерева поиска методом Монте-Карло как объекта визуализации и существующие методы визуализации больших древовидных структур, выбрать перспективный подход;
2. разработать формальную модель семантического масштабирования дерева поиска, учитывающую его особенности;
3. спроектировать и реализовать программный модуль визуализации на основе предложенной модели, развив ранее созданное решение;
4. провести вычислительный эксперимент и оценить наглядность и масштабируемость разработанного решения.

**Объектом исследования** является процесс визуализации дерева поиска методом Монте-Карло.

**Предметом исследования** являются методы семантического масштабирования применительно к визуализации дерева поиска методом Монте-Карло.

**Методы исследования** включают методы информационной визуализации (семантическое масштабирование, совмещение фокуса и контекста, степень интереса), анализ алгоритма поиска по дереву методом Монте-Карло, методы объектно-ориентированного проектирования программного обеспечения и методы экспериментальной оценки.

**Практическая значимость** работы заключается в создании модуля визуализации, позволяющего исследователям и разработчикам в наглядной форме анализировать поведение метода поиска по дереву методом Монте-Карло на больших деревьях для произвольных игр, что упрощает отладку и совершенствование вариаций метода.

**Научная новизна** работы состоит в том, что в ней впервые предложены:
1. модель семантического масштабирования дерева поиска методом Монте-Карло, в которой нормированные координаты узла являются его постоянным свойством, а не результатом работы алгоритма раскладки;
2. двухканальное кодирование статистики узла, разделяющее долю посещений, задающую ширину узла, и важность, задающую его яркость, с нижним порогом доли;
3. способ формирования набора отображаемых узлов на основе точного пиксельного критерия видимости и ограничения по объёму, не требующий ручной настройки фильтров;
4. ретроспективная компоновка, разделяющая постоянную геометрию представления и изменяющееся во времени цветовое кодирование.

На защиту выносятся следующие **положения**:
1. представление нормированных координат узла как его постоянного свойства обеспечивает неизменность положения узлов при изменении детализации, чем устраняется их смещение, присущее компоновкам с пересчётом раскладки при каждой догрузке;
2. разделение доли посещений и важности по двум каналам обеспечивает одновременную различимость доминирующих и слаборазвитых ветвей дерева и сохраняет видимой границу его раскрытия;
3. пиксельный критерий видимости с ограничением по объёму обеспечивает автоматическое согласование уровня детализации с масштабом и постоянство плотности отображаемой информации независимо от размера дерева;
4. ретроспективная компоновка обеспечивает пространственную устойчивость представления при наблюдении за ростом дерева во времени.
