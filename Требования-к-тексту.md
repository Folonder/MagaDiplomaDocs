# Памятка по написанию текста магистерской работы

Свод правил, по которым пишутся все главы. Источники: методичка кафедры
(«Методичка ВКР.docx»), стиль бакалаврской ВКР Ролдугина, замечания автора.

## Стиль и язык

- Научный академический русский. **Без разговорных и жаргонных слов** —
  под запретом «мантра», «фишка», «крутой» и т.п.
- **Русская терминология первична.** Англицизмы как обычные слова не
  использовать (не «game-agnostic», а «независимость от конкретной игры»;
  не «render-set», а «набор отображаемых узлов»). Устоявшееся английское
  название метода допускается один раз в скобках при первом упоминании
  русского термина, далее — только по-русски.
- **Связная проза, без буллет-врезок** вида «**Большой размер.** …»,
  «**Неоднородность.** …». Псевдозаголовки-ярлычки внутри абзацев запрещены —
  это выдаёт сгенерированный текст. Нумерованные перечни (задачи, требования,
  критерии) допустимы, как в ВКР.
- Не повторять одно и то же в соседних разделах.
- **Не ссылаться на другие главы работы** («как будет показано в главе 2»).
  Внутренние ссылки на рисунки/таблицы/формулы данного раздела — можно.

## Структура работы (по методичке)

- **Введение** (без сокращений!): тема, проблемная область, актуальность,
  затем строго по порядку — цель, задачи, объект, предмет, методы,
  практическая значимость, научная новизна. Положения на защиту — туда же.
- **Раздел 1** (анализ состояния вопроса): характеристика проблемной области;
  существующие способы решения (диаграммы UML/IDEF0), их недостатки; анализ;
  выбор перспективного подхода; теоретические сведения и математические модели;
  анализ аналогов-прототипов; выбор моделей/методов; точная постановка задачи
  с требованиями и ограничениями. **ВЫВОДЫ К РАЗДЕЛУ 1 НЕ ПИШУТСЯ.**
- **Раздел 2** (предлагаемый способ): способ решения; формальная модель;
  постановка задач на модели; алгоритмы. **Выводы пишутся.**
- **Раздел 3**: требования; артефакты проектирования (обязательны диаграммы
  UseCase, классов, ER при наличии БД); модель разработки. **Выводы пишутся.**
- **Раздел 4**: конструирование, тестирование, апробация. **Выводы пишутся.**
- **Заключение** (1–2 стр.), **Список источников** (≥ 25).

## Оформление (по методичке)

- Times New Roman 14, интервал 1,5, цвет только чёрный.
- Поля: левое 3 см, правое 1,5 см, верхнее 2 см, нижнее 2 см. Абзац 1,25 см.
- Заголовки: **без слова «Глава»/«Раздел»**; номер арабскими без точки
  (`1`, `2`); подразделы `1.1`, `1.1.1`. С прописной буквы, без точки в конце,
  по левому краю, без переносов и подчёркивания.
- «Содержание», «Введение», «Выводы», «Заключение», «Список использованных
  источников», «Приложение …» — **не нумеруются**.
- Рисунок: подпись по центру под рисунком — «Рисунок N – Наименование»
  (сквозная нумерация либо в пределах раздела: «Рисунок 1.1»).
- Таблица: название над таблицей слева, без абзацного отступа —
  «Таблица N – Наименование»; перенос — «Продолжение таблицы N».
- Формулы по центру, номер справа в круглых скобках: `(1.1)`.
- Объём ПЗ без приложений 60–80 страниц.

## Терминологический словарь (рабочий)

| Английский | В тексте по-русски |
|---|---|
| semantic zooming | семантическое масштабирование |
| geometric zooming | геометрическое масштабирование |
| focus + context | совмещение фокуса и контекста (фокус+контекст) |
| degree of interest | степень интереса |
| level of detail | уровень детализации |
| overview first… | сначала обзор, затем детализация |
| game-agnostic | независимость от конкретной игры |
| render-set | набор отображаемых узлов |
| icicle plot | ярусная диаграмма (icicle plot) |
| flame graph | флейм-граф (flame graph) |
| treemap | диаграмма вложенных прямоугольников (treemap) |
