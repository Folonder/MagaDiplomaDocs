# Сборка записки в LaTeX

Конвейер для текста с формулами и алгоритмами: руководитель работает
в LaTeX и правит `.tex` напрямую.

## Что установлено

- **MiKTeX** — дистрибутив TeX, компилятор `xelatex`. Недостающие пакеты
  доустанавливает сам при первой сборке;
- **TeXstudio** — редактор с подсветкой, навигацией по разделам и просмотром PDF.

Компилятор не прописан в системный `PATH`, поэтому в консоли его путь
задаётся явно (TeXstudio находит его сам).

## Как собрать

Из этой папки:

```bash
xelatex -interaction=nonstopmode main.tex
```

Нужен именно **XeLaTeX**, а не pdfLaTeX: оформление требует системного
Times New Roman, который подключается через `fontspec`. pdfLaTeX на этих
файлах выдаёт поток ошибок вида `Unicode character ... not set up for use
with LaTeX` — он просто не понимает кириллицу в UTF-8 без `inputenc`.

Для оглавления и перекрёстных ссылок сборку повторяют дважды.

## Как собрать в TeXstudio

Собирать нужно **корневой** файл — `main.tex`, `spec-main.tex` или
`article.tex`. Файлы `razdel1.tex` и `spec.tex` — вставки без преамбулы,
сами по себе они не компилируются.

Специально запоминать это не требуется: в первой строке каждого файла
стоит служебный комментарий, который TeXstudio читает сам. У вставок это
`% !TeX root = <корневой файл>` — нажатие «Собрать» из вставки соберёт
корневой документ; у корневых — `% !TeX program = xelatex`, он включает
нужный компилятор вместо pdfLaTeX, стоящего в TeXstudio по умолчанию.

## Из чего состоит

| Файл | Назначение |
|---|---|
| `main.tex` | преамбула и подключение разделов записки |
| `gost.sty` | всё оформление по методичке кафедры |
| `razdel1.tex` | текст раздела 1 |
| `spec-main.tex`, `spec.tex` | формальная постановка задачи и алгоритмы (для руководителя) |
| `article.tex` | статья на конференцию, 4 страницы, со своей преамбулой |
| `md2tex.py` | разовый перенос раздела из markdown, больше не нужен |

Статья собирается отдельно: `xelatex -interaction=nonstopmode article.tex`.
`gost.sty` она не подключает — оформление записки (14 пт, полуторный
интервал) в четыре страницы не укладывается. Шаблон конференции
не применён: когда он появится, преамбулу статьи заменяют на него,
текст и формулы переносятся без изменений.

Рисунки берутся из `images/chapter1/` и подключаются относительным путём.

## Что задаёт gost.sty

Поля 3 / 1,5 / 2 / 2 см, Times New Roman 14 пт, полуторный интервал,
абзацный отступ 1,25 см, выравнивание по ширине. Заголовки — с абзацного
отступа по левому краю, обычным начертанием, номер без точки, слов
«Глава» и «Раздел» нет. Разделы с новой страницы не начинаются. Номер
страницы внизу по центру.

Подпись таблицы — сверху слева, рисунка — снизу по центру, разделитель
дефис. Нумерация рисунков, таблиц и формул в пределах раздела. Кегль
таблиц 12 пт: методичка о нём молчит, разрешение даёт ГОСТ 7.32-2017,
п. 6.6.7.

## Отношения с docx-конвейером

Оба живут параллельно и собираются из разных источников:

- `Текст/*.md` → `Готовое/*.docx` (сборщик на docx-js);
- `LaTeX/*.tex` → PDF (xelatex).

После переноса раздела в LaTeX источником становится `.tex`; markdown
остаётся историей до тех пор, пока перенос не проверен целиком.
