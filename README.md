# Документы магистерской диссертации

Применение методов семантического масштабирования в программном модуле для
визуализации поиска по дереву методом Монте-Карло. ВолгГТУ, кафедра ПОАС,
направление 09.04.04.

Здесь только текстовая часть работы. Исходный код визуализатора — в
отдельном репозитории.

## С чего начать читать

| Файл | Что это |
|---|---|
| `Концепция/spec-main.pdf` | формальная постановка задачи и алгоритмы: три объекта, пять подзадач, псевдокод верхнего уровня |
| `Диплом/Готовое/Раздел 1.docx` | раздел 1: анализ задачи и методов |
| `Конференция Камышин 2026/Готовое/Ролдугин О.Д.(ВолгГТУ).docx` | статья на четыре страницы |

## Папки

Разложено по темам: каждая папка — отдельная работа со своими исходниками
и своим результатом.

| Папка | Что внутри |
|---|---|
| `Диплом/` | пояснительная записка |
| `Концепция/` | формальная постановка задачи и алгоритмы — то, что лежит в основе всех разделов |
| `Конференция Камышин 2026/` | статья и сведения об авторах для подачи в оргкомитет |
| `Статьи/` | журнальные публикации |
| `Руководство/` | руководство пользователя программой |
| `Справочное/` | методичка, бакалаврская работа, замечания руководителя — читаем, не правим |
| `Оформление/` | общий стиль LaTeX и правила сборки |
| `Сборка/` | скрипты, собирающие `.docx` из markdown |
| `Архив/` | редакции, которые заменены новыми |

Внутри `Диплом/` то же деление по назначению: `Текст/` — исходники разделов
в markdown, `LaTeX/` — они же в LaTeX, `Рисунки/` — иллюстрации,
`Готовое/` — собранные `.docx`. Правки вносятся в исходники: собранные
файлы перестраиваются и правки в них теряются.

## Как собрать

Пакет `docx` ставится один раз:

```bash
npm install --prefix Сборка
```

Записка и список источников:

```bash
node Сборка/build-docx.js "Диплом/Текст/Раздел 1 - Анализ задачи и методов.md" "Диплом/Готовое/Раздел 1.docx"
```

Статья на конференцию и сведения об авторах (на каждого автора выходит
свой файл):

```bash
node Сборка/build-article.js "Конференция Камышин 2026/Статья.md" "Конференция Камышин 2026/Готовое/Ролдугин О.Д.(ВолгГТУ).docx"
```

```bash
node Сборка/build-authors.js "Конференция Камышин 2026/Сведения об авторах.md" "Конференция Камышин 2026/Готовое"
```

Рисунки раздела 1 перерисовываются отдельно, результат — в
`Диплом/Рисунки/`:

```bash
node Сборка/figures-chapter1.js
```

**Перед пересборкой закройте файл в Word** — открытый документ заблокирован,
и сборка упадёт.

Сборка PDF из LaTeX описана в `Оформление/README.md`.

## Проверка вёрстки

LibreOffice и poppler на машине не установлены, отрендерить страницы
картинками нельзя. Вёрстка проверяется Word через COM: число страниц,
положение заголовков, поля. Поэтому про вёрстку корректно говорить
«проверена вычислением», а не «просмотрена».
