# Документы магистерской диссертации

Применение методов семантического масштабирования в программном модуле для
визуализации поиска по дереву методом Монте-Карло. ВолгГТУ, кафедра ПОАС,
направление 09.04.04.

Здесь лежит только текстовая часть работы: разделы записки, их исходники в
LaTeX, собранные `.docx` и `.pdf`, справочные материалы. Исходный код
визуализатора — в отдельном репозитории.

## С чего начать читать

| Файл | Что это |
|---|---|
| `LaTeX/spec-main.pdf` | формальная постановка задачи и алгоритмы: три объекта, пять подзадач, псевдокод верхнего уровня |
| `LaTeX/article.pdf` | статья на четыре страницы — концепция и алгоритм верхнего уровня |
| `Готовое/Раздел 1.docx` | раздел 1: анализ задачи и методов |
| `Готовое/Список источников раздела 1.docx` | список литературы раздела 1 |

Правки удобнее вносить в `.tex` — собранные файлы перестраиваются из
исходников и правки в них теряются.

## Как устроена папка

Разделение по назначению файлов: что пишем руками, что из этого
собирается, чем собирается и что лежит для справки.

| Папка | Что внутри | Правим руками |
|---|---|---|
| `Текст/` | исходники разделов в markdown — **единственный источник истины** | да |
| `Готовое/` | собранные `.docx`, которые отдаются руководителю | нет, пересобираются |
| `Сборка/` | скрипты сборки и генерации рисунков | да |
| `Справочное/` | методичка, бакалаврская работа, статья, замечания руководителя | нет, читаем |
| `Архив/` | редакции, которые заменены новыми, но могут понадобиться | нет |

## Как собрать раздел

Пакет `docx` ставится один раз:

```bash
npm install --prefix Сборка
```

Затем из корня проекта:

```bash
node Сборка/build-docx.js "Текст/Раздел 1 - Анализ задачи и методов.md" "Готовое/Раздел 1.docx"
```

**Перед пересборкой закройте файл в Word** — открытый документ заблокирован,
и сборка упадёт.

## Как перерисовать рисунки

```bash
node Сборка/figures-chapter1.js
```

Рисунки чёрно-белые (цвет запрещён методичкой), складываются в
`images/chapter1/`. Снимок существующего модуля берётся из
`images/chapter1/src-module.png` и переводится в оттенки серого.

## Список источников

Ведётся не отдельно, а внутри файла раздела: `Текст/Список источников
раздела 1.md` выгружается из раздела, а `Готовое/Список источников
раздела 1.docx` собирается из выгрузки. Правьте список в разделе.

## Оформление

Правила кафедры — в `Справочное/Требования-к-тексту.md`, первоисточник —
`Справочное/Методичка ВКР.docx`. Чего в методичке нет (кегль таблиц),
берётся из ГОСТ 7.32-2017 с оговоркой в тексте.

Вёрстка проверяется Word через COM: LibreOffice и poppler на машине не
установлены, отрендерить страницы картинками нельзя.
