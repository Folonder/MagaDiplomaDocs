# Оформление и сборка LaTeX

В этой папке лежит `gost.sty` — всё оформление по методичке кафедры ПОАС
ВолгГТУ. Стиль общий: его подключают и пояснительная записка, и концепция,
поэтому он вынесен из обеих папок сюда.

## Что установлено

- **MiKTeX** — дистрибутив TeX, компилятор `xelatex`. Недостающие пакеты
  доустанавливает сам при первой сборке;
- **TeXstudio** — редактор с подсветкой, навигацией по разделам и просмотром PDF.

Компилятор не прописан в системный `PATH`, поэтому в консоли его путь
задаётся явно (TeXstudio находит его сам).

## Что чем собирается

| Документ | Корневой файл | Куда входит текст |
|---|---|---|
| Пояснительная записка | `Диплом/LaTeX/main.tex` | `razdel1.tex` |
| Концепция | `Концепция/spec-main.tex` | `spec.tex` |

Собирать нужно **корневой** файл. `razdel1.tex` и `spec.tex` — вставки без
преамбулы, сами по себе они не компилируются. Из папки документа:

```bash
xelatex -interaction=nonstopmode main.tex
```

Нужен именно **XeLaTeX**, а не pdfLaTeX: оформление требует системного
Times New Roman, который подключается через `fontspec`. pdfLaTeX на этих
файлах выдаёт поток ошибок вида `Unicode character ... not set up for use
with LaTeX` — он не понимает кириллицу в UTF-8 без `inputenc`.

Для перекрёстных ссылок сборку повторяют дважды.

## В TeXstudio

Запоминать это не требуется: в первой строке каждого файла стоит служебный
комментарий, который TeXstudio читает сам. У вставок это
`% !TeX root = <корневой файл>` — нажатие «Собрать» из вставки соберёт
корневой документ; у корневых — `% !TeX program = xelatex`, он включает
нужный компилятор вместо pdfLaTeX, стоящего по умолчанию.

## Где ищется gost.sty

Корневые файлы лежат не рядом со стилем, поэтому перед `\usepackage{gost}`
каждый из них указывает путь к этой папке:

```latex
\makeatletter\def\input@path{{../Оформление/}}\makeatother
```

У записки путь на уровень длиннее — `../../Оформление/`, она лежит в
`Диплом/LaTeX/`.

## Что задаёт gost.sty

Поля 3 / 1,5 / 2 / 2 см, Times New Roman 14 пт, полуторный интервал,
абзацный отступ 1,25 см, выравнивание по ширине. Заголовки — с абзацного
отступа по левому краю, обычным начертанием, номер без точки, слов
«Глава» и «Раздел» нет. Разделы с новой страницы не начинаются. Номер
страницы внизу по центру.

Подпись таблицы — сверху слева, рисунка — снизу по центру, разделитель
дефис. Нумерация рисунков, таблиц и формул в пределах раздела. Кегль
таблиц 12 пт: методичка о нём молчит, разрешение даёт ГОСТ 7.32-2017,
п. 6.6.7.

## Отношения с docx-конвейером

Записка живёт в двух видах и собирается из разных источников:

- `Диплом/Текст/*.md` → `Диплом/Готовое/*.docx` (сборщик на docx-js);
- `Диплом/LaTeX/*.tex` → PDF (xelatex).

Пока перенос в LaTeX не проверен целиком, markdown остаётся источником
истины, а правки вносятся в оба вида. Статья на конференцию собирается
только в `.docx`: оргкомитет принимает Word, а не PDF.
